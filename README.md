## About This Repository

This repository contains the practical assignments, laboratory exercises, experiments, implementation work, documentation, screenshots, terminal outputs, and supporting materials for the **Cloud Computing** course of the **M.Tech. in Computer Science & Engineering** program at the **International Institute of Information Technology, Bhubaneswar (IIIT Bhubaneswar)**.

The repository is designed as a consolidated record of the Cloud Computing coursework completed throughout the academic term.

As new assignments are given, they will be added as separate project folders while maintaining a consistent structure for source files, documentation, execution evidence, and results.

---

# Repository Objectives

This repository is maintained to:

- Record all Cloud Computing practical assignments and experiments.
- Maintain reproducible implementation steps and commands.
- Preserve terminal execution evidence and screenshots.
- Document cloud infrastructure configuration and deployment procedures.
- Demonstrate practical use of cloud platforms and associated tools.
- Maintain an organized GitHub portfolio of the coursework.
- Provide a historical record of completed Cloud Computing activities.
